## 🎮 Gry w kolekcji

### 1. [BeatSurfer Triki - Cyber Highway](https://xardag.github.io/beatsurfer/)
- **Adres:** `https://xardag.github.io/beatsurfer/`
- **Gatunek:** Rytmiczny cyber-ślizg 3D / Synthwave
- **Sterowanie:** Kontroler Żabka Triki (żyroskop po blacie / przechył w dłoni), klawiatura (strzałki/WASD/Space/E), dotyk na telefonie
- **Funkcje:** 100% deterministyczne trasy, wbudowany generator synthwave, obsługa własnych plików MP3/WAV, mnożniki Combo, Star Power (do x8), tryb pełnego ekranu (klawisz `F` lub przycisk `⛶`).

## 🕹️ Wspierane kontrolery i platformy

1. **Kontroler Żabka Triki (BLE):**
   - Łączność przez Web Bluetooth API w przeglądarkach **Google Chrome** oraz **Microsoft Edge** (PC i Android).
   - Dwa tryby sterowania: **Biurko** (obrót kapslem po blacie) oraz **W dłoni** (przechył boczny).
   - Reakcja na kliknięcie przycisku oraz informacja zwrotna na diodzie LED.

2. **Komputer PC / Mac:**
   - Klawisze strzałek oraz `W`, `A`, `S`, `D`.
   - `Spacja` / `Shift` / `E` – akcje specjalne (np. Star Power).
   - `F` – włączanie / wyłączanie trybu pełnego ekranu.

3. **Smartfon / Tablet:**
   - Dedykowane przyciski dotykowe pod areną gry.
   - Płynne przesuwanie palcem po torach trasy (`setPointerCapture`).
   - Szybkie gesty (Swipe Up lub podwójne stuknięcie aktywujące Star Power).
